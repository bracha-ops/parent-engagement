קידום מעורבות הורים בריפוי בעיסוק בתחום הילדים

אפליקציה זו פותחה במסגרת פרויקט לתואר שני בריפוי בעיסוק, במטרה לסייע למרפאות בעיסוק לקדם מעורבות הורים בתהליך הטיפולי.

האפליקציה כוללת כלים מעשיים, רעיונות להתערבות ושאלות לחשיבה קלינית, המבוססים על הספרות המקצועית בתחום טיפול ממוקד משפחה ומעורבות הורים בטיפול.

מטרת האפליקציה

לספק למרפאות בעיסוק כלי נגיש ויישומי המסייע:

לזהות את רמת מעורבות ההורים בתהליך הטיפולי.
לזהות חסמים והזדמנויות לשיתוף פעולה.
לשלב את ההורה כמוביל וכשותף משמעותי בהתערבות.
לתרגם מטרות טיפוליות לשגרות היום-יום של המשפחה.

חשוב לדעת
